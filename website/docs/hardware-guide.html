Firmware Flashing

The source sketch LuxSense_Arduino.ino is located in the repository under firmware/LuxSense_Arduino/.

  1. Open the sketch in Arduino IDE (v2.x or legacy).
  2. Ensure the BH1750 library by Christopher Laws is installed via Library Manager.
  3. Select Arduino Uno and the corresponding COM port.
  4. Click Upload. The Uno will acknowledge queries from LuxSense Pro with ID:GY30_LUX_PRO_2026.
