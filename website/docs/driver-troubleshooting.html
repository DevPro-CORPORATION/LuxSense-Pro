USB Serial Driver Troubleshooting

Resolving COM port enumeration errors, missing USB-UART bridge drivers, and baud rate mismatches.

Symptom 1: No COM Port Appears in Settings

If the port dropdown only shows default fallback entries or scanning returns no devices:

  • Check Device Manager: Press Win + X and open Device Manager. Look under Ports (COM & LPT) or Other Devices.
  • CH340/CH341 USB Bridge: Many Uno clones use the WCH CH340 chip. If a yellow exclamation mark appears next to USB-SERIAL CH340, download and install the official WCH CH341SER driver.
  • Genuine Arduino Uno (ATmega16U2): Genuine boards use the official Arduino driver bundled with Arduino IDE (located at C:\Program Files (x86)\Arduino\drivers\).
  • USB Cable Quality: Some Micro-USB/USB-B cables are power-only. Ensure you are using a 4-conductor data-capable cable.

Symptom 2: Connection Error: Access is Denied (PermissionError)

On Windows, a COM port can only be opened by a single process at any one time.

  • Ensure the Arduino IDE Serial Monitor or Serial Plotter is closed before launching LuxSense Pro.
  • Check whether another application (such as Cura, MATLAB, or PuTTY) is occupying the COM port.

Symptom 3: Handshake Timeout ("No valid Arduino handshake received")

  • When an Arduino Uno serial port is opened, the DTR line pulses and resets the ATmega328P. LuxSense Pro pauses 2.0 seconds to allow the bootloader to finish before issuing the DISCOVER_LUX_SENSOR challenge.
  • Verify that the firmware was compiled with BAUD_RATE = 115200. If using a custom sketch with 9600 baud, change the baud rate selector in the LuxSense Pro Settings tab to 9600.
