LuxSense Pro Installation Guide

Step-by-step instructions for installing, configuring, and updating LuxSense Pro on Windows.

System Requirements

  • Operating System: Windows 10 (Version 1809 or later), Windows 11 (64-bit).
  • Hardware Interface: Standard USB 2.0 or USB 3.0 Type-A/Type-C port.
  • Memory: 512 MB RAM minimum (1 GB recommended).
  • Disk Space: 120 MB free storage for application, updater, and local SQLite history database.

Method 1: Windows Setup Wizard (Recommended)

  1. Download LuxSense-Pro-Setup-v2.1.0.exe from the Downloads section.
  2. Verify the SHA-256 hash using PowerShell: 
    Get-FileHash LuxSense-Pro-Setup-v2.1.0.exe -Algorithm SHA256
  3. Double-click the installer and follow the setup wizard prompts.
  4. The installer configures Start Menu shortcuts and registers the standalone updater bootstrapper.

Method 2: Portable Distribution (.zip)

For lab computers or non-admin workstations:

  1. Download LuxSense-Pro-v2.1.0-portable.zip.
  2. Extract the archive into any preferred directory (e.g. C:\Tools\LuxSensePro\).
  3. Launch LuxSensePro.exe directly.

User Data & Settings Safety

LuxSense Pro separates application executables from your personal data. Your configuration files, calibration profiles, and logged measurements are always saved in: 

%APPDATA%\DevPro\LuxSensePro\

When an update is installed, this directory is untouched.
